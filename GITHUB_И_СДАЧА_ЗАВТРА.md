# Как опубликовать подготовленный дипломный репозиторий в GitHub

**Проект:** Business Management & CRM Platform with an Embedded AI Assistant — **отдельно от QEDNEX**.

## Что уже находится в этом пакете

- Настоящий локальный Git-репозиторий: скрытая папка `.git`, ветка `main`, один исходный коммит **AI-assisted document import**.
- README, описание проекта, научный обзор (13 публикаций), сравнения CRM и технологий, требования, архитектура, редактируемые диаграммы, прототип, план тестирования, CSV задач для YouTrack, презентация и итоговый отчёт.
- Файлы без реальных пользовательских данных, паролей или ключей (по автоматической проверке типовых форматов).

**Важно:** исходный коммит — техническая загрузка подготовленных AI-assisted черновиков, а не подтверждение личной разработки какого-либо студента. Настоящий индивидуальный вклад каждого человека должен быть отдельным, проверяемым и отражаться в Git/YouTrack.

## Публикация (Windows)

1. Распакуйте **весь** архив, включая скрытую папку `.git`.
2. Установите [Git for Windows](https://git-scm.com/downloads/win) и [GitHub CLI](https://cli.github.com/), если их нет.
3. Откройте PowerShell в папке `Diploma-CRM-AI`.
4. Выполните:

   ```powershell
   .\PUBLISH_TO_GITHUB.ps1
   ```

   Если Windows не позволяет запустить загруженный скрипт, можно просмотреть код файла и выполнить эти команды вручную (после входа в `gh auth login`):

   ```powershell
   gh auth login
   gh repo create diploma-crm-ai --private --source . --remote origin --push
   ```

5. GitHub создаст **закрытый** репозиторий и загрузит подготовленный начальный коммит. Скрипт отказывается перезаписывать существующий репозиторий.
6. Пригласите участников команды и руководителя через **Settings → Collaborators / Access**; обеспечьте доступ комиссии до предзащиты.
7. Создайте отдельный проект в YouTrack; используйте `plans/YouTrack_Backlog.csv` как заготовку. Настоящие ID и ссылки задач появятся только после создания.
8. Сохраните реальную ссылку репозитория и YouTrack в `SUBMISSION_STATUS.md` и README.

## Что автоматизация НЕ делает

- Не создаёт аккаунты, не обходит GitHub OAuth, не использует/не записывает секретные токены.
- Не создаёт YouTrack без подключения к учётной записи.
- Не подделывает 3–5 интервью, согласие клиента, комментарии научного руководителя или вклад каждого участника.
- Не выдаёт демонстрационный HTML-прототип за готовый Backend+Frontend+AI продукт.
- Не создаёт тег `pre-defense-1`, пока руководитель и команда не проверили фактический состав сдачи.
